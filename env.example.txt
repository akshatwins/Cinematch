CineMatch V2 — Environment Setup

1. Create a new file named exactly:
   .env

2. Copy the following into it:

APP_NAME=CineMatch
ENVIRONMENT=development
TMDB_ACCESS_TOKEN=PASTE_YOUR_TMDB_ACCESS_TOKEN_HERE
TMDB_BASE_URL=https://api.themoviedb.org/3
TMDB_IMAGE_BASE_URL=https://image.tmdb.org/t/p
DATABASE_URL=sqlite:///./cinematch.db
REDIS_URL=
CORS_ORIGINS=http://localhost:8000
REQUEST_TIMEOUT_SECONDS=8

3. Replace PASTE_YOUR_TMDB_ACCESS_TOKEN_HERE with your TMDB API Read Access Token.

IMPORTANT:
- Never upload .env to GitHub.
- .gitignore is already configured to ignore .env.
- Upload .env.example to GitHub, not .env.
